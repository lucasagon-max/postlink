## FAQ

What is a social preview card?

A social preview card is the image and text people see when a
link is shared in apps like Facebook, X, Threads, Bluesky, LinkedIn, Slack, Discord, or
messaging apps.


What is a preview link?

A preview link is a shareable SocialCards link that shows your
custom card when shared and redirects visitors to your original
destination URL when clicked.


Do I need to change my website metadata?

No. SocialCards lets you create a separate preview link, so you
can customize the shared preview without changing the metadata
on the destination website.


Can I use my own domain?

Yes. PRO users can publish preview links on branded subdomains.


Can I generate cards with an API?

Yes. The API can generate preview images and links from
templates using data from your app, CMS, or product database.


Do I need an account to try it?

You can start in the editor without an account. An account is
needed when you want to save projects or use PRO features.


What do I unlock with PRO?

PRO unlocks saved projects, branded preview links, custom
subdomains, and API automation.
